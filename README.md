# cli-stealth-reader-v2

The Rust implementation of `cli-stealth-reader`, a full-screen terminal reader
for EPUB, CBZ, and PDF books with plain and code-disguised reading modes.

The migration preserves the observable behavior and user data of the TypeScript
v1 while replacing the Node.js runtime with a native binary. It opens the same
`library.db`, keeps the same positions and bookmarks, and renders the same text.

```bash
cargo run --release -p stealth-reader            # open the library
cargo run --release -p stealth-reader -- --resume
cargo run --release -p stealth-reader -- book.epub
```

Press `/` for commands, `?` for shortcuts, `m` to cycle the disguise, and `q` to
quit.

## Where things live

```text
stealth-reader        composition root: arguments, wiring, exit codes
└── reader-tui        Ratatui frame, key mapping, terminal lifecycle
    └── reader-app    reader state, layout, and the command executor
        ├── reader-core          domain: blocks, rendering, commands, pace, themes
        ├── reader-formats       EPUB, CBZ, PDF, and library discovery
        ├── reader-storage       SQLite library, settings, export/import
        └── reader-integrations  Toggl 2.0 Focus
```

Dependencies point one way, down that list. `reader-core` has no terminal,
database, archive, or HTTP dependency; `reader-app` takes the clock and the
viewport as parameters rather than reading them; `reader-tui` is the only crate
that touches a real terminal.

cargo fmt --all --check

## How parity is proven

Behavior is not compared by reading the TypeScript; it is compared by running it.
Three generated fixtures pin what v1 does, and the Rust suite asserts against
them:

| Fixture | Covers | Generated by |
| --- | --- | --- |
| `reader-core/tests/golden/render-parity.json` | 12,050 rendering cases across languages, densities, widths, spacings, and block indices | `tools/generate-render-golden.mjs` |
| `reader-core/tests/golden/command-parity.json` | 263 cases: parsing, error wording, contextual hints, the manual at five widths, suggestions | `tools/generate-command-golden.mjs` |
| `reader-formats/tests/golden/import-parity.json` | 10 EPUB and CBZ files and the canonical books v1 extracted from them | `tools/generate-import-golden.mjs` |
| `reader-storage/tests/fixtures/v1-library.db` | a real v1 database, opened and read back field by field | `tools/generate-storage-fixture.mjs` |

Regenerating a fixture requires the v1 checkout and is a deliberate act that
shows up in review:

```bash
V1_DIR=~/Development/cli-stealth-reader node tools/generate-render-golden.mjs
```

Where v2 deliberately differs — two v1 defects are fixed rather than reproduced —
[the improvements record](docs/migration/improvements.md) says what changed, why,
and which test guards it.

## Performance

Measured against the same corpus on the same machine; full numbers and the
procedure are in [the baseline document](docs/migration/performance-baseline.md).

| | v1 | v2 |
| --- | --- | --- |
| Startup | 339 ms | 0.9 ms |
| Import a 266k-word EPUB | 192 ms | 27 ms |
| Render a chapter (disguised) | 5.0 ms | 1.8 ms |
| Peak memory | 157 MB | 15 MB |
